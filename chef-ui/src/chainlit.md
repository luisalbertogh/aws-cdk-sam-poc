## Quick Start

> [NOTE!]
> This is an example of a quick start from a `bash` terminal.

To test the application locally:

- Ensure you are under the `chef-ui` folder (this folder).
- Enable the Python virtual environment: `source .venv/Scripts/activate`.
- Apply the environment variables in `.env`: `source .env`.
- From `src/`, run the application: `chainlit run app.py -w`

After a few seconds, the application will automatically load in a new web browser window showing up from `localhost:8000`.
